# Security Policy

## Supported versions

Only the latest version published to npm as
[`@adaept/ae-icon5`](https://www.npmjs.com/package/@adaept/ae-icon5) is supported. There are no
older maintained release lines — please upgrade before reporting an issue that may already be
fixed.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting instead of a public issue:

1. Go to the [Security tab](https://github.com/adaept/ae-icon5-component/security) of this repo.
2. Click **Report a vulnerability**.

This is a solo-maintained project — reports are handled on a best-effort basis, with no
guaranteed response time or SLA. Please don't disclose publicly until a fix has shipped.
